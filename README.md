# 📊 Alura Store - Análisis de Ventas

Este proyecto analiza el rendimiento de cuatro tiendas de **Alura Store** para ayudar al Sr. Juan a decidir cuál vender y así invertir en un nuevo negocio.

El análisis se realizó en **Python usando Google Colab**, evaluando cinco aspectos clave: facturación total, ventas por categoría, calificación promedio de clientes, productos más y menos vendidos y costo promedio de envío.

Los resultados muestran que **la Tienda 4 tiene el menor desempeño en facturación**, por lo que se recomienda considerarla para la venta.

## 🛠 Herramientas utilizadas
- Python  
- Pandas  
- Matplotlib  
- Google Colab

Conclusión: Con base en el análisis realizado, se recomienda que el Sr. Juan considere vender la Tienda 4
ya que es la que genera menor facturación y menor desempeño financiero, permitiendo así liberar recursos para
invertir en un nuevo negocio potencialmente más rentable.
